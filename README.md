# Tiramisu

[Русский](#русский) | [English](#english)

## English

A KISS and lightweight init for Linux and POSIX-compatible operating systems.

---

### Possibilities.

- Service managing

### Compilation.

This builds the project:

```bash
make
```

This clears everything:

```bash
make clean
```

To install the init system:

```bash
sudo make install
```

This command defaults DESTDIR to /usr/local.

# Tiramisu

Лёгкий и следующий философию KISS система инициализации для Linux и POSIX-совместимых систем

---

### Возможности

- Управление сервисами

### Компиляция

Эта комманда построит проект:

```bash
make
```

Эта комманда очистит всё:

```bash
make clean
```

Эта комманда установит Tiramisu: 

```bash
sudo make install
```

Эта комманда по началу настраивает DESTDIR на /usr/local.
